# Capli

**为 Agent 编写的文档提供真实截图。**

Capli 取自 Capture + CLI。项目计划提供 Windows 和 macOS 截图命令行工具，让 AI Agent 在写文档时发现目标窗口、获取真实截图，并把图片交给文档编辑流程。

[English](README.md) · [需求草案](docs/requirements.md)

**需求与设计阶段，尚无可运行程序或发布版本。** 下述内容是待实现的产品方向，不代表已支持的能力。

## 使用流程

1. Agent 发现并选择明确的目标窗口。
2. 工具保存截图并返回结构化元数据。
3. Agent 读取图片，确认截图内容。
4. 按需裁剪、标注，准备文档配图。
5. 由 Agent 的文档编辑工具插入图片，或使用生成的图片引用。

## 建议范围

- Windows、macOS 使用一致的 CLI 接口。
- 明确的窗口目标和坐标约定。
- JSON 输出、稳定错误码和环境诊断。
- 本地保存图片及来源信息。
- 面向文档编写的示例和 Agent 使用说明。

网页截图、标注、文档适配器、MCP 以及桌面辅助程序仍在讨论中；平台能力差异会明确记录。
